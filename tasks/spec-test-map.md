# 仕様とテストの対応

各テスト名はコード内の名前です。対応はテストの存在を示し、直近の実行結果を示すものではありません。複数の条件を含む受け入れ条件では、挙げたテストが一部を確認する場合があります。

- API: [tests/api/tasks.test.ts](../tests/api/tasks.test.ts)
- 画面: [tests/e2e/tasks.spec.ts](../tests/e2e/tasks.spec.ts)
- 検索の単体テスト: [tests/unit/search.test.ts](../tests/unit/search.test.ts)
- `%s` を含む名前は複数の入力で実行されるテストです。

## [タスクの完了](task-completion.md)

| 受け入れ条件 | 対応するテストと未確認の範囲                                                                                                                                                                                                                                |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-01        | 画面: `完了タスクを未完了に戻すとフィルター表示が変わる`、`選択したステータスのタスクだけを表示する`                                                                                                                                                        |
| AC-02        | API: `新規タスクを未完了で作成する`。従来のSQLiteデータを移行する条件は当時の仕様であり、MySQL移行時には既存データを引き継がないと判断した。                                                                                                                |
| AC-03        | API: `%sへの変更をMySQLへの再接続後も保持する`。画面: `完了タスクを未完了に戻すとフィルター表示が変わる`。APIサーバープロセスを再起動するテストは未確認。                                                                                                   |
| AC-04        | 画面: `選択したステータスのタスクだけを表示する`、`完了タスクを未完了に戻すとフィルター表示が変わる`                                                                                                                                                        |
| AC-05        | 画面: `再読み込みすると未完了のみを選択する`、`選択したステータスのタスクだけを表示する`                                                                                                                                                                    |
| AC-06        | 画面: `未完了のみのとき最後のステータスを解除できない`、`完了のみのとき最後のステータスを解除できない`                                                                                                                                                      |
| AC-07        | 画面: `編集したタイトルを再読み込み後も表示する`、`空のタイトルを追加すると入力エラーを表示する`、`タスク作成で500が返ると保存エラーを表示する`、`タイトル編集で500が返ると保存エラーを表示する`、`完了状態の保存で500が返るとエラーを表示し状態を維持する` |
| AC-08        | API: `真偽値以外の完了状態を400で拒否する`、`不正なID %s の更新に404を返す`、`更新時に不正なJSONを400で拒否する`、`想定外のDB障害には500を返す`                                                                                                             |

## [MySQLへの変更](mysql-migration.md)

| 受け入れ条件 | 対応するテストと未確認の範囲                                                                                                                                                                             |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| AC-01        | APIと画面テストはMySQLを使用する。Composeの起動と接続先設定を直接検証するテストは未確認。                                                                                                                |
| AC-02        | API: `新規タスクを未完了で作成する`、`MySQLへの接続を開き直しても更新済みタイトルを一覧に表示する`、`削除したタスクは同じMySQLへ再接続した一覧に現れず、他のタスクは残る` など。完了と削除の対応も参照。 |
| AC-03        | API: `%sへの変更をMySQLへの再接続後も保持する`、`MySQLへの接続を開き直しても更新済みタイトルを一覧に表示する`。APIサーバープロセスの再起動は未確認。                                                     |
| AC-04        | APIとE2Eのテスト用MySQLは実行スクリプトで用意される。分離そのものを検証するテストは未確認。                                                                                                              |
| AC-05        | [README](../README.md) に手順を記載。文書の内容を検証するテストは未確認。                                                                                                                                |
| AC-06        | SQLiteデータを取り込まないことを直接検証するテストは未確認。                                                                                                                                             |
