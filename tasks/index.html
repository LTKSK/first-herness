タスク一覧

タスク一覧の現在の仕様

タスク一覧には、選択されたステータスとタイトルの検索条件に一致するタスクを表示する。表示件数を示し、各タスクのタイトル、完了状態、期限と操作を対応付ける。

検索とステータス

  • 検索は入力のたびにタイトルを部分一致で絞り込む。英字の大小文字は区別せず、検索語の前後の空白は除く。
  • 未完了と完了の少なくとも一方を選ぶ。最後に選んだステータスは解除できない。一覧には1つ以上の選択が必要なことを表示する。
  • 画面を開いた直後と再読み込み後は、検索語を空にし、未完了のみを選択する。
  • タスクがない場合は追加方法を案内する。タスクはあるが条件に一致しない場合は、検索語やステータスの変更を案内する。

タスクの操作

  • 完了と未完了を切り替えられる。タイトルと期限を編集・保存でき、編集をキャンセルできる。削除は確認後に行う。
  • 操作はキーボードでも利用でき、編集開始時は入力欄にフォーカスする。編集の保存またはキャンセル後は編集ボタンにフォーカスを戻す。完了、削除、検索中の編集で対象の行が消えたときは検索欄にフォーカスを移す。
  • 狭い画面と長いタイトルでも内容と操作を利用できる。
  • タスクの作成、期限、保存のエラーと削除のエラーを表示する。

確認方法

  • 画面テスト: 検索条件に合うタスクがないと一覧に条件の変更を案内する、ステータスの選択欄を表示すると1つ以上の選択が必要と分かる、狭い画面で長いタイトルのタスクを表示すると編集と削除を画面内で操作できる、キーボードで編集を開始してキャンセルすると元のタイトルが残る、キーボードで検索語を入力すると一致するタスクだけを一覧に表示する、キーボードで完了ステータスを選ぶと完了タスクが一覧に表示される、キーボードでタイトルを編集して保存すると一覧に変更後のタイトルを表示する、キーボードで削除を選び確認をキャンセルするとタスクが一覧に残る。
  • 既存の検索、絞り込み、期限、更新、削除とエラーのテストも同じ画面テストにある。

他の機能の現在の仕様は整理中です。

課題: タスクに期限を追加する

既存のタスク管理アプリに任意の期限を追加してください。

受け入れ条件

  • タスクの作成・編集時に期限を入力または解除でき、一覧で確認できる。期限は日付だけを扱い、時刻やタイムゾーンは扱わない。
  • APIのタスク表現に dueDate を追加する。値は実在する日付を表す YYYY-MM-DD 形式の文字列か null とする。
  • 作成時に dueDate を省略した場合は null とする。更新時に省略した場合は既存の期限を維持し、null の場合は期限を解除する。不正な期限は400とする。
  • 既存のDBを開いた場合、既存タスクを保持して期限を null にする。アプリを再起動しても変更は保持される。
  • タイトルの既存の仕様と、作成・一覧・更新の既存の動作を維持する。入力・保存エラーは画面に表示する。
  • この変更に必要なAPIテストと画面E2Eテストを追加・更新する。既存の受け入れ条件を弱めない。
